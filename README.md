### 🏆 Proyecto Destacado: La Parada del Sabor

Construí de cero un **Sistema POS Full-Stack y Plataforma de Delivery** en tiempo real para un negocio de comida, gestionando todo el ciclo de vida del software:

- **Frontend Reactivo:** Modalidad cliente de autoservicio (`/pedir`) y panel administrativo POS (`/`).
- **Real-Time Híbrido:** Sincronización de facturas en vivo mediante `Supabase Realtime` (WebSockets) con fallback de polling.
- **Transacciones Atómicas:** Manejo estricto de inventario en gramos/mililitros usando *Triggers de PostgreSQL* para evitar inconsistencias de stock en ventas concurrentes.
- **Seguridad Profunda:** Rate-Limiting persistente en base de datos para login y Row Level Security (RLS) que blinda el acceso por completo.
- **Desempeño:** Migración a Next.js Turbopack y síntesis de audio nativa con `Web Audio API` para cero dependencias externas.
